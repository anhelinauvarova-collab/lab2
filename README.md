## Рішення
- **Фреймворк:** не використовується, увесь CSS власний (`css/style.css`), щоб на захисті пояснювати кожну властивість.
- **Шрифти (Google Fonts):** Playfair Display для заголовків, Manrope для тексту. Підібрано як найближчі за накресленням; якщо у вашому макеті інші шрифти, замініть їх тут і в змінних `--font-heading` / `--font-body`.
- **Змінні `:root`:** пастельна колірна палітра (`--color-accent`, `--color-bg-alt`, `--color-footer-bg` тощо), відступи, радіуси заокруглення, ширина контейнера.
- **Контейнер:** `max-width: 75rem`, `margin-inline: auto`, бічні поля через `padding`. Фонові смуги секцій розтягуються на всю ширину.
- **Flexbox:** шапка, головний екран (Hero), внутрішня структура карток товарів, блок переваг, вирівнювання та нижній рядок підвалу.
- **CSS Grid:** сітка карток каталогу (3 колонки → 2 → 1) та сучасне 4-колоночне компонування підвалу (`footer-grid`).
- **Брейкпоінти:** `75rem` (1200px), `64rem` (1024px) та `48rem` (768px) / `40rem` (640px).
- **clamp():** `h1`, `h2`, `h3`, `.lead` і вертикальні відступи секцій для плавної масштабованості.
- **Мобільне меню:** без JavaScript, через прихований `checkbox` і `label`.
